# 打鍵パス比較 - 英語追加（中国語は後日）

## 背景

`B.html#13` の打鍵パス比較セクションにおいて、日本語の構文が決定済み。
同じ手法で英語・中国語の比較も追加したい。

## 決定済み事項

### 日本語（確定）
- **構文**: `にほんごにゅうりょくにさいてきかされたはいれつ`
- **意味**: 日本語入力に最適化された配列
- **結果**: path-preview.html で計算済み

### ツール
- `public/works/yamato/docs/path-preview.html` — インタラクティブなパスライン可視化ツール
  - ひらがな入力でリアルタイムプレビュー
  - 上下キーで履歴比較
  - 拗音(にゅ,りょ等)・促音(っ)対応済み
  - 各文字後にホームポジションリセットする方式で計算
- `public/works/yamato/docs/calc-lines.js` — Node.js用の計算スクリプト（旧版、path-preview.htmlが最新）

### レイアウトデータ
```javascript
// QWERTY
const QR = [
  [Q,W,E,R,T,Y,U,I,O,P,[],]],
  [A,S,D,F*,G,H,J*,K,L,;,'],
  [Z,X,C,V,B,N,M,,,.,/]
];
// 大和配列
const YR = [
  [M,Y,R,W,P,X,L,Q,C,',[]],
  [K,S,T,N*,H,F,A*,O,I,E,/],
  [Z,D,B,G,J,V,U,-,,,.]
];
// * = home position keys (左人差指, 右人差指)
```

## やりたいこと（英語のみ。中国語は後日）

### 英語の打鍵パス比較
- **コンセプト**: 大和配列でも英語が打てることを示す
- **縛り/キーワード**: `english`, `typing`, `type` などを含む自然な英文
- **メッセージ性**: 「英語もそのまま打てます」的なニュアンス
- **方式**: QWERTYの物理キーで英語を打つ vs 大和配列の物理キーで英語を打つ
  - 大和配列ではキー位置が違うので、同じアルファベットでも異なる指の動きになる

### path-preview.html の改修
- **タブUI追加**: 日本語 / English / 中文 の3タブを設ける
  - 今回は日本語（確定済み）+ 英語を実装
  - 中国語タブは枠だけ用意して後日対応
- 日本語タブ: 現行のひらがな→ローマ字変換そのまま
- 英語タブ: アルファベット直接入力（ローマ字変換なし、小文字→大文字変換のみ）
- 最終的に `B.html` の打鍵パスセクションにも3言語切り替えを反映

## 注意事項
- `typing-compare.js` が現在の打鍵アニメーションエンジン
  - 現在は日本語(ローマ字)のみ対応
  - 英語/ピンインの場合はローマ字変換不要で、直接アルファベットキー列を使用
- ホームポジションリセット方式を採用している（各文字後に指がホームに戻る）
- path-preview.html のカテゴリ分析が参考になる:
  - **カテゴリA (大和有利)**: T, N, O, I, E — QWERTYでは非ホーム、大和ではホーム
  - **カテゴリB (中立)**: A, S, F, H, K — 両方ホーム
  - 英語/ピンインでもこのカテゴリが有効
